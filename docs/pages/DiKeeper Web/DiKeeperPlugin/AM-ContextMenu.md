# Addin Manager

Automatically open RVT and RFA files with the correct Revit version and quickly check the version of RVT and RFA files.

![App Manager - Context Menu](../../../../assets\images\GIFs\ContextMenu\AM-Context.png)

## Check Revit version

You can check the Revit version of one or more files after selecting them. From the same window, you can also choose the Revit version you need to open each file.

1. Select one or more RVT or RFA files, or right-click a single file.

2. Right-click the selection and click on "Show more options".

3. Find "DiRoots" and then click on "Check Revit version".

4. Review the Revit version for each selected file. From there, choose the Revit version to open any file if you need.

![App Manager - Check Revit version](../../../../assets\images\GIFs\ContextMenu\AM-RevitVersion.gif)  
<sub>Note: the version on the image may not reflect the [latest version of App Manager](https://diroots.com/apps/diroots-app-manager/#downloadForm).</sub>

## Open Revit file with the correct Revit version

Use this option to open an RVT or RFA file with the Revit version the file requires.

If the required Revit version is installed and the file is not workshared, the file opens directly. Otherwise, App Manager shows options to select the Revit version and, when needed, additional workshared settings.

1. Right-click on the RVT or RFA file.

2. Click on "Show more options".

3. Find "DiRoots" and then click on "Open Revit file with the correct Revit version".

![App Manager - Open Revit file with the correct Revit version](../../../../assets\images\GIFs\ContextMenu\AM-OpenRevitFile.gif)  
<sub>Note: the version on the image may not reflect the [latest version of App Manager](https://diroots.com/apps/diroots-app-manager/#downloadForm).</sub>

## Support for workshared files

When opening files through DiRoots App Manager, you can see whether a file is workshared and choose how to open it:

- As a central file
- As a local file
- As a detached file

This is supported when using **Check Revit version** or **Open Revit file with the correct Revit version**, for one or more files.

![App Manager - Support for workshared files](../../../../assets\images\GIFs\ContextMenu\AM-Workshared.gif)  
<sub>Note: the version on the image may not reflect the [latest version of App Manager](https://diroots.com/apps/diroots-app-manager/#downloadForm).</sub>

## Open in audit mode

You can open files in Audit mode. Audit mode always opens the file in a new Revit session. The interface displays the message: *The file must be opened in a new session meaning it will be opened apart.*

This option is available from the same open flow when checking the Revit version or specific cases of using Open Revit file with the correct Revit version.
